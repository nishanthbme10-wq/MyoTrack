# MyoTrack – Wearable EMG-Based Muscle Rehabilitation & Fatigue Monitoring System

**Measure the Muscle. Track the Recovery.**

## 📌 Project Overview

MyoTrack is a wearable Surface Electromyography (sEMG)-based system developed to monitor muscle electrical activity and support rehabilitation progress tracking.

The system uses surface EMG electrodes to capture electrical signals generated by muscle contractions. An ESP32 microcontroller acquires and processes the signals, while Wi-Fi communication transfers the collected data to a web dashboard for real-time visualization and monitoring.

The project aims to provide a low-cost and wearable solution for muscle activity assessment and rehabilitation monitoring.

## 🎯 Project Objectives

The main objectives of the MyoTrack system are:

- To capture electrical signals generated by muscle contractions using surface EMG electrodes.
- To acquire and process muscle signals using the ESP32 microcontroller.
- To extract important EMG features such as Root Mean Square (RMS), Mean Absolute Value (MAV), and EMG envelope.
- To analyse muscle activation patterns and monitor EMG-based fatigue trends.
- To support exercise repetition tracking during rehabilitation activities.
- To develop a web dashboard for real-time EMG waveform visualization and muscle activity monitoring.
- To enable rehabilitation session monitoring and comparison for tracking recovery progress.

## 🏗️ System Architecture

MyoTrack follows a simple workflow to capture, process, and visualize muscle electrical signals.

**System Workflow:**

Muscle Activity → Surface EMG Electrodes → EMG Signal Conditioning → ESP32 Microcontroller → Wi-Fi Communication → Web Dashboard → EMG Data Visualization

### Working Flow

1. **Signal Acquisition:** Surface EMG electrodes capture electrical signals produced during muscle contractions.
2. **Signal Conditioning:** The EMG sensor amplifies and conditions the acquired signals.
3. **Data Processing:** ESP32 receives and processes the EMG signals.
4. **Wireless Communication:** The processed data is transmitted through Wi-Fi.
5. **Data Visualization:** The web dashboard displays the received EMG readings and waveform for monitoring.

## 🔩 Hardware Components

The MyoTrack prototype uses the following hardware components:

- **ESP32 Development Board:** Used for EMG data acquisition, processing, and Wi-Fi communication.
- **Surface EMG Sensor / Bio-Amplifier:** Captures and amplifies electrical signals generated by muscle activity.
- **Surface EMG Electrodes:** Detect muscle electrical activity from the skin surface.
- **3.7V Li-ion Rechargeable Battery:** Provides portable power to the system.
- **TP4056 Charging Module:** Used for rechargeable battery charging.
- **XL6009 Boost Converter:** Used to increase the battery output voltage as required by the circuit.
- **Connecting Wires:** Used to establish electrical connections between the hardware components.

## ⚙️ Working Principle

The MyoTrack system works by capturing electrical signals produced by skeletal muscles during contraction and transmitting the acquired data to a web dashboard.

1. **Muscle Signal Detection:** Surface EMG electrodes are placed on the target muscle to detect electrical activity during contraction.
2. **Signal Amplification:** The EMG sensor amplifies and conditions the weak muscle signals.
3. **Data Acquisition:** The ESP32 microcontroller reads the EMG signal through its analog input.
4. **Signal Processing:** The acquired readings are processed to observe muscle activity and extract relevant EMG features.
5. **Wi-Fi Transmission:** ESP32 sends the collected readings wirelessly through Wi-Fi.
6. **Dashboard Visualization:** The web dashboard receives and displays the EMG readings and waveform for real-time monitoring.

This process helps observe muscle activity during rehabilitation exercises and supports further analysis of muscle performance.
