# MyoTrack – Wearable EMG-Based Muscle Rehabilitation & Fatigue Monitoring System

**Measure the Muscle. Track the Recovery.**

## 📌 Project Overview

MyoTrack is a wearable Surface Electromyography (sEMG)-based system developed to monitor muscle electrical activity and support rehabilitation progress tracking.

The system uses surface EMG electrodes to capture electrical signals generated by muscle contractions. An ESP32 microcontroller acquires and processes the signals, while Wi-Fi communication transfers the collected data to a web dashboard for real-time visualization and monitoring.

The project aims to provide a low-cost and wearable solution for muscle activity assessment and rehabilitation monitoring.
